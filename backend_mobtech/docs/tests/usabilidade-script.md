# Testes de Usabilidade

Objetivo: avaliar clareza do fluxo e percepção de valor pelo passageiro urbano.

Participantes: 3–5 usuários potenciais (estudantes/ moradores de Anápolis).

Tarefas:
T1) Abrir o app e autorizar/recusar localização
T2) Definir origem e destino
T3) Selecionar uma rota multimodal sugerida
T4) Visualizar no mapa paradas e linhas próximas
T5) Acompanhar o ônibus e o ETA dinâmico

Para cada tarefa, registrar:
- Sucesso/fracasso (1/0)
- Tempo aproximado (segundos)
- Dificuldades relatadas
- Nota de facilidade (1–5)
